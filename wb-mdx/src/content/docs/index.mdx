Welcome to the Winter Boot documentation. Winter Boot is a modern PHP 8 microservices framework inspired by Spring Boot, bringing attribute-driven dependency injection, AOP, REST routing, async task execution, caching, transactions, and scheduling to the PHP ecosystem. Whether you know Spring Boot or are starting fresh, these docs cover everything you need to build, configure, and deploy production-ready PHP microservices.

## What a Winter Boot service looks like

A service is a plain PHP class with attributes. The framework finds it at startup, wires its dependencies, and serves its routes from the built-in HTTP server:

```php title="src/HelloController.php"
#[RestController]
class HelloController
{
    #[Autowired]
    private HelloService $helloService;

    #[GetMapping(path: '/api/hello')]
    public function hello(#[RequestParam(required: false)] string $name = 'World'): ResponseEntity
    {
        return ResponseEntity::ok()->withJson([
            'message' => $this->helloService->sayHello($name),
        ]);
    }
}
```
