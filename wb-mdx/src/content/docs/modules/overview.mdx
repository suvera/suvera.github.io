The Winter library ecosystem is a set of optional packages that extend the [Winter Boot](/winter-boot/introduction) framework with integrations for databases, message queues, object storage, search, and distributed infrastructure. Every library implements the framework's [module system](/winter-boot/core/module-system) contract and registers beans automatically, so once you enable a module in `application.yml` you can `#[Autowired]` its templates and clients anywhere in your code.

## Choose a library

Match your use case to a library and package.

| Need | Use | Package |
| --- | --- | --- |
| Relational database with ORM entities | [Doctrine](/winter-boot/modules/doctrine) | `suvera/winter-doctrine` |
| Redis client for cache or key/value work | [Redis](/winter-boot/modules/data-redis) | `suvera/winter-modules` |
| Memcached client for lightweight caching | [Memcache](/winter-boot/modules/data-memcache) | `suvera/winter-modules` |
| Embedded in-memory DB launched with the app (Redis, Ignite, Memcached, Hazelcast) | [Memdb](/winter-boot/modules/memdb) | `suvera/winter-memdb` |
| Event streaming and pub/sub | [Kafka](/winter-boot/modules/kafka) | `suvera/winter-modules` |
| Managed AWS message queue | [SQS](/winter-boot/modules/sqs) | `suvera/winter-modules` |
| S3-compatible object storage | [S3](/winter-boot/modules/s3) | `suvera/winter-modules` |
| Full-text search and analytics | [OpenSearch](/winter-boot/modules/opensearch) | `suvera/winter-modules` |
| Background task orchestration across nodes | [DTCE](/winter-boot/modules/dtce) | `suvera/winter-modules` |
| Service discovery (Consul or Netflix Eureka) | [Eureka](/winter-boot/modules/eureka) | `suvera/winter-eureka` |
| Application security policies | [Security](/winter-boot/modules/security) (planned) | `suvera/winter-modules` |

## Installation

Winter libraries are distributed as separate Composer packages so you install only what you need, and some libraries require additional PHP extensions. Follow the [Installation](/winter-boot/installation) guide (Docker is recommended) for the package list and the per-library extension matrix, then return here to pick the right library.

## Enabling a library

Every library plugs in through the same [module system](/winter-boot/core/module-system). Declare the module class in your `application.yml` under `modules:`:

```yaml title="application.yml"
modules:
    - module: 'dev\winterframework\kafka\KafkaModule'
      enabled: true
      configFile: 'config/kafka-config.yml'
```

Read [The Module System](/winter-boot/core/module-system) for the full contract, load order, and how to build your own modules.
