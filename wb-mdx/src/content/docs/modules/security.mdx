Winter Security is a planned module. The name is reserved in the `suvera/winter-modules` package, but no code ships yet.

<Aside type="caution">
  Do not add a security module to `modules:` in `application.yml` — there is no module class to load yet.
</Aside>

Watch the [winter-security directory](https://github.com/suvera/winter-modules/tree/master/winter-security) on GitHub for updates. This page will document configuration and usage once the module is released.

## Securing an application today

Until then, handle security in your own code:

- Authenticate requests with an [interceptor](/winter-boot/web/interceptors) before they reach the controller.
- Enforce authorization with a [custom AOP attribute](/winter-boot/core/aop) on controller or service methods — see the [RBAC](/winter-boot/howto/rbac) and [ABAC](/winter-boot/howto/abac) guides for complete examples.
- Keep logins in [sessions](/winter-boot/core/request-sessions), stored in your database or Redis.
